Job & Knock

Install the full-screen iPhone version with the proper Home Screen icon.

Why this installer?
The normal Add to Home Screen launcher loses standalone mode when it hands off to Google. This profile installs a Web Clip that opens the real Apps Script app full-screen and is allowed to follow Google's redirects without showing Safari controls.
Install Full-Screen App
  1. Tap the button above in Safari.
  2. Open Settings and tap Profile Downloaded.
  3. Tap Install and confirm.
  4. Launch Job & Knock from the new Home Screen icon.
Open App Directly
The profile contains one removable Home Screen Web Clip only. It does not configure accounts, VPN, certificates, passcodes, or device restrictions. You can remove it later in Settings → General → VPN & Device Management.
